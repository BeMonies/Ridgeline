# Ridgeline visual identity

Source: Ridgeline visual identity kit **v1.2** (designed 2026-09-29). These are verbatim copies of the
specification files the app follows. `brand/ridgeline.tokens.json` is the canonical token set.
Logo geometry is copied from the kit SVGs into `_source/src/brand.jsx`; do not redraw it.
Inter (`fonts/Inter-Variable.ttf`) is bundled unchanged with its OFL license. Michroma is not shipped:
it appears only as outlined paths inside the wordmark.
